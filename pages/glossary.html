Computer vision glossary

Plain-language definitions of common terms. Model-specific behavior depends on implementation and validation.

Computer vision

Methods that let software analyze images or video and produce information about visible content.

Object detection

A computer-vision task that identifies objects in an image and typically associates each detection with a location and class label.

YOLO

An acronym used by a family of object-detection model approaches. Specific model versions, capabilities, licenses, and performance differ; the name alone does not establish suitability.

Bounding box

A rectangular region around an object or area of interest, often represented by coordinates and used to display a detection or annotation.

Annotation

A human- or tool-created label attached to data, such as a class name or object boundary, for organizing, evaluating, or training a vision system.

Edge and cloud

Edge processing runs computation near the camera or data source. Cloud processing uses computing resources accessed over a network. Each option has tradeoffs in latency, connectivity, operations, capacity, and data handling.

Inference

Running a trained model on input data to produce a prediction or other output. Inference output is not automatically a verified fact.

False positive and false negative

A false positive is an alert that does not match the event of interest; a false negative is a missed event of interest. Definitions and impact depend on the specific task and decision process.

Human review

A process in which a person evaluates system output, context, or uncertainty before deciding what action to take.

ROI

Return on investment compares a defined benefit with costs over a chosen period. The calculators on this site show only an illustrative time-value scenario from user inputs and do not calculate verified project ROI.
